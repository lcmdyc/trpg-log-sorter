# 跑团 Log 分拣整理系统 (TRPG Log Sorter)

一个专为 TRPG玩家和 Log 整理创作者设计的**快速分拣与合并工具**。支持多群聊、多文件并行合并，通过键盘快捷键或丝滑的拖拽交互，将混乱的原始聊天记录快速分流整理。（本工具为vebcoding产物。）

**在线使用地址**：[点击访问你的 GitHub Pages 网址](https://lcmdyc.github.io/trpg-log-sorter/)

---

## 推荐工作流 (Recommended Workflow)

本系统是跑团 Log 整理工作流中的**分拣环节**。为了获得最佳的使用体验，强烈推荐与以下优秀开源工具搭配使用：

```
┌──────────────────────────────┐      ┌──────────────────────────────┐      ┌──────────────────────────────┐
│  1. 导出原始记录 (QQ)     │ ───> │  2. 极速分拣与合并 (本系统)    │ ───> │  3. 导出干净的单窗 Log       │
│  使用 qq-chat-exporter 导出   │      │  按键/拖拽分流到 HO1~HO4/水聊 │      │  保留原始列，方便后续排版     │
└──────────────────────────────┘      └──────────────────────────────┘      └──────────────────────────────┘
```

1. **第一步（导出）**：使用 [@shuakami](https://github.com/shuakami) 开发的 [qq-chat-exporter](https://github.com/shuakami/qq-chat-exporter)，将 QQ 群聊记录导出为规范格式的 `.xlsx` 或 `.csv` 表格（包含 `时间`、`发送者`、`消息内容` 等列）。
2. **第二步（分拣）**：将导出的一个或多个表格上传至本系统。系统会自动识别文件名中的群组标记（如 `group_群聊A_chat.xlsx`，会被标记为群聊A），并按照时间线严格升序合并。
3. **第三步（分流）**：使用键盘快捷键 `1-9` 、鼠标拖拽、鼠标点击分拣按钮，将消息秒速分流到各个 HO 分窗或水聊窗，最后点击下载即可获得完美分类的干净 Log。

---

## 核心特色 (Features)

* **极速键盘分拣**：按下键盘 `1-9` 键，即可将当前待处理的首行消息直接分发到对应的分窗，单手即可完成海量 Log 分流。
* **多文件智能合并**：支持一次性上传多个表格。系统会自动提取文件名中的群组作为“来源标签”，并严格按照“时间”列进行全局升序重排，完美解决多群并开、多视角 Log 合并的痛点。
* **丝滑拖拽修正 (Drag & Drop)**：
  * **跨窗移动**：不小心分错？直接用鼠标左键按住卡片，拖拽到目标分窗即可。
  * **位置微调**：支持在分窗内上下拖拽调整卡片顺序。
  * **防抖设计**：引入“隐形占位判定区”，拖拽悬停时下方卡片会自动平滑下移让出空隙，判定范围大且绝不闪烁。
* **保留完整原始列**：分拣和分流过程中，系统在后台完整保留了表格的所有原始列字段（如消息类型、地区、状态等）。导出时，将输出包含并集表头的完整 CSV 文件，绝不丢失任何原始数据。
* **现代美观的 UI**：基于 Tailwind CSS 与 Lucide 图标库设计，界面优雅、核心信息（发送者与消息内容）高度聚焦。

## 快速开始 (Quick Start)

### 1. 准备数据
使用 [qq-chat-exporter](https://github.com/shuakami/qq-chat-exporter) 导出你的 QQ 跑团群聊记录，获取 `.xlsx` 或 `.csv` 文件。

### 2. 导入与合并
* 打开本系统网页，点击右上角的 **“上传表格”** 按钮（支持多选文件一次性导入）。
* 如果想先体验功能，可以点击 **“加载多列测试数据”**，系统将自动加载模拟的日常跑团群聊对话。

### 3. 开始分拣
* 观察底部 **“待处理队列”** 的第 1 行（高亮显示）。
* 按下键盘上的数字键（如 `1` 代表第一个分窗，`2` 代表第二个，以此类推），或者直接点击中间控制台的对应按钮，该行数据就会进入对应的分窗。
* 如果分拣错误，直接在上方分窗中用鼠标拖拽卡片进行修正。

### 4. 导出结果
点击对应分窗右上角的 **“下载”** 图标，即可导出该分窗专属的、保留了全部原始列的 `.csv` 表格。
